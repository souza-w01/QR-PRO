# Gerador de QR Code

Projeto criado do zero, sem modificar nada existente.

## O que faz
- Crie vários QRs, cada um com seu link
- Edite o link de um QR já criado (o QR se atualiza)
- Use qualquer link externo, ex: WhatsApp
- Baixe cada QR em PNG
- Copie o link
- Exporte e importe backup em JSON

## Como usar
Abra o arquivo `index.html` no navegador.

## Hospedagem
Envie os arquivos para o GitHub e ative o GitHub Pages.
